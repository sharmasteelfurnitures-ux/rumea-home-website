# Rumea Home™ — Brand & Design Guide

## Brand Essence
- **Brand Name:** Rumea Home™ (Wordmark: \umea home®\ in all lowercase)
- **Tagline:** \"Thoughtful Furniture for Modern Homes\"
- **Brand Slogan:** \"More Than Furniture\"
- **Brand Voice:** Warm, modern, honest, grounded, conversational.

## Color Palette
| Name | Hex | Usage |
|------|-----|-------|
| Espresso | \#2C2926\ | Headings, primary CTAs, header text, dark footer |
| Warm Sand | \#D8C9B5\ | Secondary accents, pill tags, dividers, borders |
| Warm Ivory | \#F7F4EE\ | ALL page backgrounds (Never use stark white for pages) |
| Dark Ivory | \#F0EBE2\ | Alternating section backgrounds, table headers |
| Muted Olive | \#78806A\ | Accent tags, badges, WhatsApp buttons, icon highlights |
| Soft Taupe | \#A69B8C\ | Secondary body copy, strikethrough prices, meta text |

## Typography
- **Headings / Display:** \Plus Jakarta Sans\ (Bold 700 / SemiBold 600)
- **Body / UI:** \Inter\ (Regular 400 / Medium 500 / SemiBold 600)

## Design Rules
1. Never use pure white (\#FFFFFF\) for full page backgrounds.
2. Never use pure black (\#000000\) for body text or headlines.
3. Keep corner radiuses soft and inviting (\12px\, \16px\, \24px\).
4. Maintain mobile-first touch ergonomics (minimum 44px touch targets).
